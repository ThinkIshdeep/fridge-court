# Explain this project in an interview

## One-minute explanation

A reviewed household stock ledger and feasible meal planner that keeps OCR estimates separate from confirmed inventory.

## Be ready to explain

- The input schema, processing steps and user-visible output.
- The implemented method and why a simpler baseline is useful.
- The exact evaluation unit, split and metric definitions.
- A failure mode you reproduced and a test that would detect regression.
- What persists, how long jobs are handled and how cancellation behaves.
- Which proposed advanced features are still extensions.

## Accurate résumé wording

- Built a reviewed inventory ledger with receipt parsing, optional OCR and explicit consumption/waste events.
- Implemented integer meal optimization with hard stock, diet and budget constraints and regression checks for feasibility.

Run and inspect the code before using these descriptions. Do not describe unimplemented research extensions as completed work.
