# Demo walkthrough

The video is a 21-second captioned sequence of three screenshots captured from the V2 application. The QA host uses the same standalone view and engine. This is an edited walkthrough, not a continuous real-time recording.

## 1. Review confirmed stock

The household ledger stores explicit quantities, units and user-entered dates.

## 2. Parse before committing

Receipt text becomes reviewable lines. Parsing alone does not silently change inventory.

## 3. Optimize a feasible meal plan

Integer optimization respects available ingredients, diet and budget. Dates are not food-safety guarantees.
